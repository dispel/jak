# Getting help with jak

- **How do I use it?** Read the [documentation](https://jak.readthedocs.io), or run `jak --help` and `jak COMMAND --help`.
- **Something is broken, or I have a question.** Search the [issues](https://github.com/dispel/jak/issues), and open a new one if yours is not there. Include the output of `jak --version` and `python3 --version`, your operating system, and the command you ran with its full output.
- **I found a security problem.** See [docs/security.rst](docs/security.rst) for how to report it.

jak is maintained on a best-effort basis, so there is no guaranteed response time. Which Python versions and operating systems are supported is listed in [docs/supported-platforms.rst](docs/supported-platforms.rst).
